About DFS

Definition

Depth First Search (DFS) is a graph traversal algorithm that explores as far as possible along each branch before backtracking.

How DFS Works

  1. Select a starting vertex.
  2. Mark the vertex as visited.
  3. Visit an unvisited neighbour.
  4. Continue exploring deeper into the graph.
  5. Backtrack when there are no unvisited neighbours.
  6. Continue until all reachable vertices have been visited.

Data Structure Used

Stack / Recursion

Time Complexity

O(V + E)

Space Complexity

O(V)

Python Implementation

def dfs(graph, start):

    visited = set()

    def visit(node):

        if node in visited:
            return

        visited.add(node)

        for neighbour in graph[node]:
            visit(neighbour)

    visit(start)

    return visited

Space Complexity

O(V)

DFS requires additional space for the visited vertices and recursion stack.
