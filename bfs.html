Breadth First Search

Interactive exploration of Breadth First Search

About BFS

Definition

Breadth First Search (BFS) is a graph traversal algorithm that explores vertices level by level. It uses a queue data structure to keep track of vertices that need to be visited.

How BFS Works

  1. Select a starting vertex.
  2. Mark the starting vertex as visited.
  3. Add it to the queue.
  4. Remove a vertex from the queue.
  5. Visit all its unvisited neighbours.
  6. Add those neighbours to the queue.
  7. Repeat until the queue becomes empty.

Data Structure Used

Queue

Time Complexity

O(V + E)

Space Complexity

O(V)

Python Implementation

def bfs(graph, start):

    visited = set()
    queue = [start]

    while queue:

        node = queue.pop(0)

        if node not in visited:

            visited.add(node)

            for neighbour in graph[node]:
                queue.append(neighbour)

    return visited
